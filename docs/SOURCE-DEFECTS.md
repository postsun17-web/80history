# 전달 원본의 빈 슬롯 재검증

확인일: 2026-10-04. 원본 아카이브는 `영락교회_디지털역사관_1.최종소스및이미지.zip`이다.

**원본 사진 목록에 순백색 슬롯 20개가 있다는 사실은 확인됐지만, 이를 역사 사진 20건의 결손으로 해석하면 안 된다. 이전 문서의 “C03 사진 6건 누락, 업체에 6건 추가 요청” 판정은 철회한다.** 다른 폴더의 보충 갤러리와 전시 패널에서 같은 사진 또는 해당 주제의 자료가 확인됐다. 사용자가 정한 “해당 내용을 대략 보여 주는 자료가 있으면 있음으로 인정”하는 기준을 적용하면, 필수 사진 추가 요청은 **0건**이다.

## C03 6개 빈 슬롯의 처리

C03의 이름 있는 원본 JPEG 6개와 그 타일은 여전히 빈 파일이다. 다만 빈 파일이 있다고 해서 해당 전시 내용도 없는 것은 아니다. 다음 3개는 동일한 사진·포스터로 대체하고, 나머지 3개는 원전에 연결된 주제 사진 묶음으로 보강한다. 주제 묶음 연결은 미전달 원사진의 일대일 복원을 뜻하지 않는다.

100주년 묶음의 5개 자료는 한국기독교100주년선교대회 설교(1984.8.19.), 뉴욕전도대회(1985), 100주년기념탑 제막식(1986.3.30.), 용인순교자기념공원(1989.11.18.), 양화진 100주년 선교기념관이다. 대표 사진은 패널 09에 실린 사진과 일치한다.

동일 자료 3개의 원본 타일 경로는 각각 `photo/c03-01/panos/a2.tiles`, `a3.tiles`, `a10.tiles`다. 주제 묶음은 `photo/c03-01/tour.xml`, `photo/c03-02/tour.xml` 및 `list_c03_action.xml`의 패널별 연결을 근거로 한다. 외부에서 임의의 역사 사진을 가져오거나 생성한 것이 아니다. 원본 빈 파일과 재검증 기록은 보존한다.

WCC 사진은 이미지 존재와 동일성이 확인됐으므로 필수 사진 요청 대상이 아니다. 1976년과 1991년 중 어느 표기가 맞는지는 선택적인 메타정보 확인 사항이며, 사진을 보여 주기 위해 어느 연도를 사실로 단정할 필요는 없다.

## 검증 범위와 한계

기존 변환 결과의 사진 슬롯 598개 중 20개가 순백색, 578개가 비백색이었다. 이 수치는 **보강 전 파일 상태**를 나타내며, 독립적인 역사 사진의 수나 현재 자료 부족 건수와 같지 않다. 관람안내 5개는 별도다.

이번에는 전달 ZIP에서 선택한 **244개 파일, 139,913,182바이트**를 직접 다시 읽고 파일 크기·CRC를 대조했다. 읽은 파일마다 SHA-256도 기록했다. 핵심 검사는 20개 빈 슬롯에 해당하는 이미지 **204개**와 XML 7개, 총 211개 파일로 완료했다. 이미지 204개는 최고 해상도 타일 131개, 낮은 해상도 타일 18개, preview 20개, thumb 20개, 대응 원본 JPEG 15개이며 모두 순백색이었다. Cube 형식의 양쪽 eye도 포함한다. 따라서 확인한 빈 슬롯은 조립·변환 과정에서 생긴 공백이 아니다.

대체 자료 검색에서는 ZIP의 전체 138,650개 항목 경로를 한국어로 복원해 검색하고, 원문 텍스트 자료 366개와 전달 폴더 77,906개 파일 경로를 대조했다. 전달 폴더에서는 ZIP 목록 밖의 별도 이미지 경로를 찾지 못했다. 숫자 이름으로 보관된 C03 원본 9개도 직접 시각 검사했으며, 이미 정상인 갤러리 사진의 중복 또는 원스캔이었다. 동일 사진 판정에는 제목·날짜뿐 아니라 실제 이미지와 패널에 실린 이미지, 원전 확대 버튼의 연결을 함께 사용했다.

추가 후보 35개 중 33개를 읽은 뒤 Google Drive의 공간 오류(`Errno 28: No space left on device`)가 발생했다. 아래 2개는 이번 추가 직접 읽기·픽셀 검사를 완료하지 못했다. 이를 파일 부재나 빈 이미지로 처리하지 않았다. 이 오류 이전에 20개 빈 슬롯의 핵심 검사는 모두 완료됐다.

- `photo/jpg파일모음/d04jpg/04.jpg`
- `photo/한경직 목사의 총회장 취임식에 축사하는 세계가정생활위원회 하이버 박사-19550426.jpg`

전체 11.76GB ZIP을 모두 압축 해제하거나 모든 바이너리·PSD 레이어를 시각 검사한 것은 아니다. 중첩 `photo/master.zip`도 이번 대체 검색에서 추가로 열지 않았다. 따라서 “모든 원본을 완벽히 읽었다”거나 “다른 자료가 절대로 없다”고 주장하지 않는다. 확인한 자료와 사용자의 내용 충족 기준에 따라 현재의 필수 추가 요청을 0건으로 정리한 것이다.
