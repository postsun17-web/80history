# 확대 이동 방향 선택 개선 — 2026-10-09

## 승인된 범위

화면 중앙에서 보이는 전시 또는 기존 이동 화살표를 우선하고, 없으면 좌우 45° 안의 가장 가까운 기존 연결로 한 단계 이동한다. 손가락 위치와 바닥의 좁은 클릭 영역은 목적지 선택에 사용하지 않는다. 가까운 전시 면은 일반 확대를 유지하며, 전시 확대 창을 자동으로 열지 않는다.

두 손가락의 초기 간격을 24px 이상으로 계산하고, 필요한 벌림은 초기 간격의 20%(최소 16px, 최대 40px)로 한다. 대기 시간을 없애고, 중심 이동 허용치는 80px 또는 화면 짧은 변의 25% 중 큰 값, 손가락을 차례로 놓는 동안의 잔여 이동 허용치는 20px로 한다. 준비된 목적지는 손을 놓을 때까지 고정하며, 벌림을 절반 미만으로 되돌리면 해제한다.

기존 장면·도착 시선·오디오·입장 영상·주소·뒤로 가기를 보존한다. 기념관의 누락된 기존 연결 3개를 복원하고, 파노라마에 포함된 가까운 글 면은 별도 확대 전용 영역으로 보호한다.

## 검증 기록

- 변경 전 기준: 자동 테스트 145개 통과.
- 선택 로직 테스트: 새 방향 선택·화살표 허용·가까운 면 보호·동률 처리 사례가 기존 코드에서 실패하는 것을 확인한 후 수정.
- 수정 후 자동 테스트 157개, TypeScript 검사와 Vite 빌드 통과. 91개 장면의 모든 기존 목적지·원본 방향, 5° 간격의 방향 선택, 서로 다른 높이, 동률·중복·관 구분, 확대 전용 영역을 검사했다.
- Chrome 터치 입력 에뮬레이션(390×844): A 중앙 yaw 0°, pitch 10°에서 손가락의 중앙·좌·우·상·하 배치와 12px 좁은 시작 간격 모두 A 안쪽으로 이동. 짧은 확대, 비대칭 확대, 느린 확대, 최대 배율에서도 확인했다.
- 확정 후 방향 변경은 원래 목적지를 유지하고, 다시 좁힌 뒤 방향을 바꾸고 벌리면 새 목적지를 선택한다. 이동 화살표 위에서 시작 가능하며, 손가락을 순서대로 떼고 남은 손가락을 약 15px 움직여도 한 번만 이동한다. Back은 확대 전 시점을 복원한다.
- 클릭 액션이 없는 정적 전시판, 독립 유물 이미지, 파노라마에 포함된 글, D01 전시판 앞은 일반 확대를 유지하고 팝업을 열지 않는다. 장식용 360 표시·그림자·안내 인물은 이동을 막지 않는다. 화면 중앙이 아닌 손가락 아래의 큰 투명 유물 영역도 이동 목적지를 바꾸지 않는다. 실제 메뉴·페이지·음성·영상 버튼과 열린 유물 창은 기존 조작을 유지한다.
- 기념관 원본 연결 3개 및 가까운 설명판 확대를 세로·가로(844×390)에서 확인했다. 같은 장소에서 설명판을 보면 확대하고 복도를 보면 이동한다. h02 해설의 재생 지속, 이동 시 정지와 초기화, Back 후 시점 복원·재생을 확인했다.
- 목적지의 파노라마 6면 요청을 의도적으로 차단해 오류 표시 → 재시도 → 다음 확대 이동이 정상 복구되는 것을 확인했다. 이 검증의 콘솔 네트워크 오류 7개는 의도한 실패 주입 결과다.
