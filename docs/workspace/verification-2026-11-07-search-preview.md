# 검색 결과 미리보기 0.2.1

## 변경

검색 목록을 제목·출처·대표 발췌 하나로 줄였다. 이전에는 문서당 최대 3개 × 약 210자였으며, 이제 실제 원문의 연속된 약 160자 구간을 사용한다. 제목은 최대 두 줄, 출처는 한 줄, 발췌는 PC 두 줄·모바일 세 줄로 제한한다.

서로 다른 검색어를 가장 많이 포함하는 문단을 고르고, 동점이면 원문 순서를 따른다. 선택 문단에서도 검색어가 모인 구간을 우선한다. 유니코드 결합 문자와 검색어를 자르지 않도록 경계를 확장하므로 긴 검색어의 발췌는 160자를 넘을 수 있다. 화면의 줄수 제한은 그대로 적용된다. 떨어진 문단을 이어 붙이거나 AI로 요약하지 않는다.

제목·발췌 클릭은 기존 전체 정제 본문과 해당 문단으로 연결한다. 본문 읽기·결과 복귀·기사 원본 링크·주소 처리 경로는 유지한다. 제목·출처에만 일치하면 첫 본문 문단을 보여준다. 문서 전체 AND 검색, 순위, 20건 단위 페이지, 코퍼스 250건은 유지한다. Worker 응답의 기존 snippets 배열에는 대표 발췌 한 개를 반환한다.

## 화면 검증 범위

처음에는 Work의 브라우저 사용 설정 때문에 검증이 보류됐으나, 사용자가 설정을 켠 뒤 Chrome을 연결해 미리보기와 운영 사이트를 확인했다. 임시 모바일 화면 크기는 검증 후 원래대로 복원했다.

- PC에서 `한경직` 검색 90건, 첫 페이지 결과 20건과 발췌 20개를 확인했다. 실제 발췌 높이는 최대 2줄, 출처는 1줄이었다.
- 두 번째 결과 페이지에서 `『영락교회: 창립10주년』 발간과 교회의 사명`을 열면 전체 3문단과 원본 기사 링크가 표시되고 `search-p1`로 이동했다. 결과 복귀 후 2/5 페이지와 선택 항목의 초점을 유지했다.
- 모바일 390×844에서 발췌 높이는 최대 3줄, 문서 전체 scrollWidth와 clientWidth는 모두 390px로 가로 넘침이 없었다.
- `한경직 피난`은 23건을 유지했다. `我則見天地一新` 발췌를 클릭하면 HWP 자료 `영락교회 창립10주년`의 전체 1,093문단 중 `search-p3`로 이동했다.
- 브라우저 뒤로가기는 검색 결과를 복원했다. Escape로 닫으면 예배 장면과 자료 검색 버튼 초점으로 돌아왔으며 콘솔 오류는 없었다.
