# 자료 검색 0.2.0 검증 기록

## 변경 범위

역사관의 영락연계 CHATBOT 메뉴와 오른쪽 챗봇 빠른 메뉴를 자료 검색으로 교체했다. 두 위치는 동일한 전체 자료 검색 창을 연다. 기념관이나 개별 전시에 검색 버튼을 추가하지 않았다. AI 답변, OpenAI API, 외부 검색 API, 서버 검색 기능을 사용하지 않는다.

버전은 package.json과 잠금 파일에서 0.1.0 → 0.2.0으로 올렸다. 변경 전 소스와 G드라이브 실행 도구를 먼저 `deb6583cdfc60c442668d71b1713da902cf36e56`에 커밋하여 원격 main과 `backup/pre-search-2026-11-06` 태그를 일치시켰다. 변경 전 테스트 193개가 통과했고 관람 자산 복원 ZIP 주소 38개가 모두 응답했다.

## 데이터와 자동 검사

- 등록 HTML 기사 224건과 HWP 문서 26건, 총 250문서 / 13,479문단을 수집했다.
- 기사 1,103문단, HWP 12,376문단, 의미 있는 이미지 대체 텍스트 76개를 포함했다. 제목만 남은 기사는 없다.
- HWP 표 200개는 셀 좌표로 정렬했으며 원본 순서만 사용한 표는 없다.
- `museum.ps1 import-search`를 두 번 실행하여 corpus, catalogue, 감사 기록의 바이트 일치를 확인했다.
- 최종 테스트 210개가 모두 통과했다. 정규화·순위·AND 검색·하이라이트·페이지·주소·Worker 오류·원문 추출과 실제 코퍼스 검색을 검사한다.
- 로컬 빌드는 공개 관람 자산 66,557개의 크기와 SHA-256 검사를 완료한 뒤 TypeScript 검사와 Vite 빌드에 성공했다.
- 느린 DriveFS 디렉터리 사전 검사를 최대 32개 병렬 읽기로 개선했다. 실제 디렉터리 전체와 링크 검사를 유지하며 기존 안전성 테스트도 통과했다.

## 브라우저 확인

Chrome에서 로컬 미리보기와 Vercel 미리보기를 확인했다.

- `한경직`: 90건, 페이지당 20개. 두 번째 페이지에서 기사 본문을 열고 결과로 돌아오면 해당 결과와 페이지를 복원한다.
- `我則見天地一新`: HWP 자료 `영락교회 창립10주년` 한 건과 일치 문단을 찾는다. 전체 정제 본문 1,093문단을 읽으며 원본 HWP 다운로드 링크는 없다.
- 문서 주소 새로고침과 브라우저 뒤로가기로 검색어·결과 페이지·문서·문단을 복원한다.
- `없는말XYZ <script>`는 결과 0건을 안전하게 표시한다. 구 `exhibit=chatbot` 주소는 검색 창을 연다.
- 모바일 390×844에서 `한경직 피난` 23건을 표시하고 가로 넘침이 없다. 닫으면 모바일 메뉴 버튼으로 초점을 돌린다.
- 검색 입력에 문자가 있어도 Escape 한 번으로 닫고, 오른쪽 자료 검색 버튼으로 초점을 돌린다.
- 상단 영락연계에서 연 검색 창을 닫으면 접힌 하위 버튼 대신 영락연계 메뉴 제목으로 초점을 돌린다. 최종 Vercel 미리보기에서도 확인했다.
- 역사관의 기존 예배 장면을 유지하고 한경직목사기념관 입구와 역사관 복귀 버튼을 확인했다. 기념관에 새 검색 버튼은 없다.

- 운영 주소: https://youngnak-museum-poc.vercel.app/
- 개별 배포: https://youngnak-museum-9wsykyub5-postsun17-webs-projects.vercel.app/
- 최종 미리보기: https://youngnak-museum-mnne14oip-postsun17-webs-projects.vercel.app/

운영 주소에서 최종 JS `index-BgY5rPR5.js`를 확인했다. 자료 검색 메뉴 두 곳, `한경직` 90건과 첫 페이지 20건, 한자 구절의 HWP 본문 1,093문단과 일치 문단 이동을 확인했다. 닫으면 기존 예배 장면을 유지하고 자료 검색 버튼으로 초점을 돌린다. 해당 확인 과정의 브라우저 콘솔 오류는 없었다.

배포 실행에서도 테스트 210개, 관람 자산 66,557개 검사, TypeScript와 로컬 빌드가 통과했다. Vercel 서버의 전체 자산 복원·빌드가 완료된 후 운영 별칭이 갱신됐다. CLI 로그인은 기존 계정으로 갱신했으며 로그인 정보는 사용자 프로필에 유지했다. 로그인 정보나 원문 파일을 저장소에 추가하지 않았다.

소스 복원 지점은 변경 전 `backup/pre-search-2026-11-06`, 배포한 자료 검색 버전 `v0.2.0`이다. Git push 자체로 자동 배포되지는 않으므로 태그 복원 후 운영 반영은 별도 배포 명령으로 진행한다.

## 범위와 복원

사진·스캔·삽입 개체는 OCR하지 않았다. 원문 텍스트와 설명이 있는 이미지 대체 텍스트를 검색한다. 인쇄 페이지 번호를 추정하지 않는다. 원본 HWP, TAR, 챗봇 모델, 로그인 정보는 Git과 웹 배포에 포함하지 않는다.

빌드의 기존 큰 청크 경고와 main.ts의 정적/동적 import 경고는 남는다. 검색 Worker와 본문은 별도 청크로 지연 로드한다. 로컬 dist에는 관람 자산을 중복 복사하지 않으며 Vercel 서버의 기존 전체 자산 복원·빌드를 유지한다.

자세한 재수집·복원 방법은 [자료 검색 운영과 복원](document-search.md), 문서별 추출 근거는 [코퍼스 감사 기록](search-corpus-audit.json)에 있다. 실행 로그는 형제 `museum-workspace/logs`에 보존한다.
