# 입구 교회 상단 연결 오류 수정 (2026-10-04)

입구에서 위를 올려다보면 교회의 첨탑·지붕이 하늘로 잘려 보였다. 원본 교회 사진은 정상이며, krpano의 위·아래 큐브 면을 PSV 기본 방향으로 읽은 것이 원인이었다. 같은 각도(0, -45, 120)로 원 운영 사이트와 수정 전·후 화면을 비교해 확인했다.
