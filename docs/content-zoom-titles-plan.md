# 전시 확대와 콘텐츠 제목 수정

2026-10-05 승인된 계획의 실행 기록이다.

## 범위

- OpenSeadragon 6.1.1의 공통 평면 이미지 확대를 Canvas로 전환한다. 투명 이미지의 숨겨진 RGB가 드러나는 합성 오류를 해결하며 원본 이미지와 3D·360도 뷰어는 변경하지 않는다.
- 기존 이미지 피라미드, 드래그·핀치·확대 버튼과 최대 확대 범위를 유지한다. 직접 이미지 확대의 기본 배경은 `#EEE8DD`, 사진 갤러리는 기존 어두운 배경이다.
- 원본 판독 중 흰 글자가 있는 투명 전시판을 확인했다. 사용자에게 선택지를 제시하고, 별도 응답이 없는 상태에서는 권장안인 ‘흰 글자 자료만 어두운 배경’으로 진행한다고 알렸다. 해당 예외는 검토 목록의 `matte: "dark"`와 판단 근거로 기록한다.
- 전시판 207개, 로비 안내 4종의 원본 PNG·확대 JPG, 본문 224개, 갤러리 603개를 대조한다. 의미가 정확한 기존 제목은 보존한다.
- `src/data/content-titles.json`에 식별자, 표시 제목, 원문 출처, 판단 근거를 저장한다. 원본 XML·미디어·공간명·`full-museum.json`은 보존한다.
- 공통 제목 조회를 패널 클릭, 크게 보기, 페이지 선택, 접근성 설명과 공유 주소에 적용한다. URL의 `+` 호환 처리는 알려진 공간 ID에만 한정한다.

## 작업과 검증

렌더러·주소·공통 제목 조회는 주 작업자가 구현하고, A / B·D / C·공통 콘텐츠를 세 검토자가 분담한다. 실제 이미지와 전체 본문을 읽고 검토 목록의 정확한 키와 출처를 검사한다.

단위 테스트로 제목의 공백·한글·실제 `+`·`&`, 과거 공간 URL, 오래된 제목의 교정, 전체 콘텐츠 목록을 검증한다. 실제 Chrome에서 전시판 전체 로딩, A·B·C·D·로비의 전체 보기/2배/4배와 이동 후 복귀, 큰 사진, 반복 열기·닫기, 모바일 터치를 검증하고 캡처를 남긴다.

이동 기능이 있는 미리보기 브랜치에서 공통 수정을 검증한 뒤, 복원 기준 커밋 `14b0309` 위에 이미지·제목 수정만 적용한다. 기존 Vercel 프로젝트 `youngnak-museum-poc`에 반영하고, 이동 편의 기능은 별도 브랜치와 로컬 미리보기에 유지한다. 배포용 원본 미디어 아카이브는 재가공하지 않는다.

관련 렌더링 근거: [OpenSeadragon의 premultiplied alpha 설정 논의](https://github.com/openseadragon/openseadragon/pull/2776). 선택한 Canvas 방식은 동일 원본의 브라우저 비교에서 글자·투명도·그림자를 정상 표시했다.
