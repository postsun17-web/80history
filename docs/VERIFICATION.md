- E 입구에서 C방으로 돌아가는 표시와 브라우저 뒤로 가기를 확인했습니다. 이동 버튼의 중복 기록을 발견해 마커 클릭 처리 중복을 제거했으며, 키보드 Enter 이동도 다시 확인했습니다.
- E 입구 파노라마 요청을 강제로 중단했을 때 C방 장면과 주소가 유지되고 오류 안내가 표시됐습니다. 요청 차단을 해제한 뒤 다시 불러오기 버튼으로 E 입구에 정상 진입했습니다.
- 자산 생성기의 E방 한 면 렌더 완료 신호와 1024px 결과를 확인했습니다. 잘못된 렌더 서버 주소에서는 생성이 실패하는 것도 확인했습니다.
- 모바일 390×844에서 E방 직접 주소, 접힌 안내도, 이동 표시와 하단 공간 목록을 확인했습니다. 기존 A방 패널과 토마스 선교사 사진 팝업을 열었고 콘솔 오류는 없었습니다.
- Vercel Preview `dpl_5bQbBQnGzPf9twW4BUWNnoynxmq1`가 READY 상태로 배포됐습니다. 일반 주소에는 프로젝트의 Vercel 로그인 보호가 적용되어 있어, 검토용 공유 링크를 별도로 생성했습니다(30일 유효).
- 배포된 페이지에서 C방 오른쪽 → E 입구 → E 안쪽을 다시 이동했고, E방 파노라마 여섯 면 모두 HTTP 200으로 응답했으며 브라우저 콘솔 오류가 없었습니다.
- Preview를 기존 `youngnak-museum-poc.vercel.app` Production 주소로 승격했습니다. 새 Production 배포 `dpl_7dAHk54VHkWbzCSjtErkfPhv9jDM`의 READY 및 도메인 연결을 확인했고, 공개 주소에서 C방 오른쪽 → E 입구 이동과 콘솔 오류 없음도 다시 확인했습니다.

E방은 역사관 원본에 없는 가상 확장 공간입니다. C방에서 보이는 문은 원본 벽면을 편집해 시범 프로젝트 자산으로 만든 것이며 원본 납품 파일은 그대로입니다. E방 파노라마는 같은 3D 공간에서 두 시점을 렌더링했으므로 구성 요소의 위치는 일치합니다. C구역의 세부 전시 팝업 및 실기기 Safari·Android/iPhone 테스트는 아직 수행하지 않았습니다.

## 자동 검사

- `npm test`: URL/각도/시야각 5개 + 이력별 시점 복원 1개, 총 6개 통과.
- `python tools/test_articles.py`: 본문 이미지 보존 및 스크립트/외부 URL 제거 검사 통과. 이미지 누락 테스트의 실패를 확인한 뒤 수정.
- `python tools/verify_assets.py`: 자산 1,521개 해시·참조, 고해상도 타일 1,440개 크기, 설명문 이미지 3개 확인. 75.86MiB.
- `npm run build`: TypeScript와 Vite 빌드 통과. Three.js/PSV/사진 뷰어를 포함한 초기 JS 약 1.08MB, gzip 약 281KB로 Vite 청크 크기 권고가 남음.
- 자산 생성 시 원본 최고 해상도 면과 재분할 무손실 WebP의 픽셀 일치를 검사.

## 실제 브라우저 확인

Codex의 Chromium 기반 브라우저에서 데스크톱 1280×720 및 모바일 폭 390×844로 확인했습니다.

- 시작 안내 열기/닫기, 로비 → A존 → 역사 전시 이동, 실제 파노라마와 안내판 표시.
- 전시 페이지 1→2→4 변경, 페이지별 연결 자료 목록.
- 원본 설명문 렌더링, 사무엘 마펫 사진 표시 및 확대 UI.
- 원시 `+`와 `%2B` 장면 직접 주소, 사진 직접 주소, 브라우저 뒤로 가기 시 패널/페이지 복원.
- 모바일 바깥 문서 너비 390px / scrollWidth 390px로 전체 페이지 가로 넘침 없음.
- 전자책 29종, 음악부 필터 선택 시 해당 3종만 표시.
- 대화상자에서 방향키를 눌러도 배경 파노라마 시점이 바뀌지 않음.
- 영상 닫기 전 오류 재현: 닫힌 대화상자에 iframe 1개가 남음. 수정 후 닫힌 대화상자 iframe 0개.

독립 코드 검토에서 제기된 4건(본문 이미지 누락, 숨겨진 영상 재생, 뒤로/앞으로 시점 손실, 대화상자 방향키 충돌)을 수정했습니다.
