# C·공통 콘텐츠 제목 검토 결과

- 출력: c-common.json, schemaVersion 1.
- 검토 범위: C01~C05 실제 패널 이미지 45개, C 관련 HTML 28개와 신문 HTML 21개 전문, 로비 PNG 아이콘 4개와 JPG 설명 팝업 4개, 갤러리 XML 캡션 177개.
- 빈/파일코드 캡션은 실제 갤러리 이미지와 부모 패널을 추가 열람했다. 도움말 5개 화면의 문구를 읽고 기능별 제목으로 복원했다.
- 각 페이지·기사·갤러리 ID 전수 일치와 모든 근거 파일/명시 XML scene ID 존재를 자동 검증했다. 저장소 및 원본 매체는 변경하지 않았다.

## 주요 제목 교정

- C02:1 승인 제목: 보린의 정신과 영락사회복지재단의 발자취. 1939년 보린원, 1957년 영락원, 1990년 재단 역사를 근거로 한다.
- C01:6은 실제 숭실대학 재건·한경직기념관, C01:7은 보성여자중·고등학교다. 원래 메타데이터 제목 순서가 반대였다.
- C03:9는 한국기독교 100주년 선교대회·기념사업, C03:10은 한국기독교총연합회 창립이다.
- C05:7 소제목에는 테님어, 본문에는 테딤 부족·테딤어 신약성경이 명시된다. 본문에 맞춰 테딤어 및 신약성경으로 제목을 교정했다. 이미지 자체는 보존한다.
- C05:8 원본 표제는 선교지와 장기적인 관계 구축이다.
- 로비 C/D 제목은 각각 영락교회와 한국기독교 / 영락교회 5대 본질이다.

## 기존 원본 링크의 별도 불일치 (이번 제목·이미지 범위에서 미수정)

- C01:6 이미지=숭실, 핫스폿=보성(c01_05·06 및 c01 갤러리 23·14·15).
- C01:7 이미지=보성, 핫스폿=숭실(c01_04·newpaper19 및 c01 갤러리 8~13).
- C05:6 루카이어 성경 패널의 더보기 링크 html/c04_01.html은 교회 개척 원칙 내용이다.
- pages.sources에는 계약에 따라 연결 HTML도 기록했지만 위 불일치는 reason에 명시했다. 관련 없는 HTML 내용을 이미지 제목의 증거로 사용하지 않았다.

## 날짜·명칭 충돌과 공백

- c01:1 입학기념사진: XML 1948.9.4. vs 파일명/패널 1947.9.4. 제목에서 연도 제외.
- c01:8 숭실 임시교사: XML 베들레헴 성전 vs 패널 예루살렘 성전. 공통 확인 사항인 영락교회 건물·숭실 임시교사만 표시.
- c03:8 / c03-01:2 동일 WCC 방문 사진: 패널 1976.6.16. vs 사진 XML 1991.6.16. 날짜 제외. source-defects.ts 기존 안내와 일치.
- c05:4 러시아 찬양단: 패널 1991.10.18., XML 1992.10.18., 사진 인쇄 날짜 1992.10.19. 날짜 제외.
- c04-07:0 날짜 1946.26.은 월일을 추정하지 않고 제외.
- c04-01:6은 XML이 광장교회-미확인이라 특정 교회명 제외.
- c01:0은 실제 RGB 전체가 흰색이며 캡션 00 외 내용이 없다. 사건을 만들지 않고 내용이 없는 원본 이미지로 표시했다. 이것은 콘텐츠 제목을 복원할 수 없는 유일한 예외다.
- c03:7/8/9/10/12/16의 원래 큐브 파일은 공백이지만 source-defects.ts가 검증된 사진 또는 컬렉션으로 복원한다. 이 항목들은 공백으로 이름 붙이지 않고 실제 복원 대상 제목과 XML 근거 scene을 기록했다.

## 배경 매트

- 기본 아이보리 유지. 실제 이미지에서 투명 영역에 흰색 본문/도입문이 있는 C01 10쪽, C04:1, C05:1에만 matte:dark 권고(총 12쪽).
- 나머지 C 패널은 아이보리 대비에 적합한 어두운 글씨 또는 이미지 안의 밝은 판이 있다.
- 로비 JPG는 배경색이 원본에 이미 포함되어 있고 PNG의 글자는 아이보리에서 읽을 수 있어 dark를 추가하지 않았다. 갤러리에는 매트 옵션을 추가하지 않았다.
