# 챗봇을 자료 검색으로 전환

사용자가 승인한 실행 범위: 기존 영락연계 CHATBOT 메뉴와 오른쪽 챗봇 빠른 메뉴를 자료 검색으로 교체한다. 두 메뉴는 같은 전체 자료 검색 창을 연다. 콘텐츠별 검색, 별도 진입 버튼, 분류 필터는 추가하지 않는다.

## 데이터와 기능

- 등록 기사 224건과 나라지식정보 한글 문서 26건의 제목·출처·정제 본문을 검색한다.
- AI 답변, OpenAI API, 외부 검색 API, 모델·벡터 데이터베이스는 사용하지 않는다.
- 브라우저 Web Worker에서 검색하며 검색 화면과 본문은 처음 열 때 지연 로드한다.
- 검색어는 1–200자, 유니코드 NFC·대소문자·공백을 정규화한다. 여러 단어는 문서 전체에서 AND 조건으로 찾는다.
- 순위는 제목 완전 일치, 제목 포함, 출처 포함, 본문 포함 순이다. 동점은 제목과 문서 ID로 안정 정렬한다.
- 문서별 결과 한 개, 최대 발췌 3개, 페이지당 20개. 선택하면 전체 본문과 해당 문단을 읽는다. 원본 HWP는 공개 파일에 넣지 않는다.
- 기존 exhibit 주소에 검색어·결과 페이지·문서·문단을 저장한다. 구 chatbot 주소는 검색으로 연결한다. 전시 위치·시선·오디오·포커스 복귀를 보존한다.

## 실행 순서

1. 변경 전 0.1.0과 로컬 실행 도구를 main 및 `backup/pre-search-2026-11-06` 태그에 보존하고 원격 커밋을 확인한다.
2. 재현 가능한 오프라인 HWP/HTML 추출기, 정제 데이터와 감사 기록을 만든다.
3. 검색 엔진·Worker·대화상자·주소 처리를 구현하고 회귀 검사한다.
4. 브라우저에서 데스크톱·모바일·검색과 본문·뒤로가기·기존 관람 기능을 확인한다.
5. 0.2.0으로 올려 Vercel에 배포하고, 완료 소스와 `v0.2.0` 태그를 GitHub에 푸시한다. 복원 방법과 검증 범위를 기록한다.

편집은 museum-web, 실행은 형제 museum-workspace이며 검사·수집·빌드·실행·배포는 museum.ps1을 사용한다.
