확인일: 2026-10-04. 애플리케이션 파일은 수정하지 않았다.

ZIP의 전체 138,650개 항목에서 한국어를 복원한 경로를 검색하고, 366개 원문 XML·HTML·JS 등의 텍스트 자료와 전달 폴더의 77,906개 파일 목록을 대조했다. 전달 폴더에서는 ZIP 목록 밖의 별도 이미지 경로가 발견되지 않았다. 별도 파일은 ZIP 자체와 이관 안내서였다. 확인에 사용한 C03 본·보충 갤러리 XML 및 action XML은 ZIP의 크기와 CRC에 일치했다.

추가 14개에는 현재 활성화된 원전의 직접 확대 버튼 연결이 없다. 5개의 a07 blank 슬롯과 5개의 00 슬롯은 식별 가능한 제목이 없다. d01:5,16 및 d04:2,3도 일대일 대체 자료를 확정하지 못했다. 다만 d01:16의 주석 처리된 과거 버튼은 할렐루야찬양대 패널 위치를 가리키고, 그 패널과 동일한 사진이 `html/photo/d01_38a.jpg`에 있다. 사진 안의 날짜 2025.6.4와 기사 alt 날짜 2025.07.09가 상충한다. 제목 없는 슬롯의 자동 복원 근거로는 별도 취급해야 한다.

C03의 숫자 이름 원본 9개(`image00002`, `03`, `04`, `05`, `06`, `07`, `08`, `09`, `11`)를 전부 직접 시각 확인했다. 각각 이미 정상인 c03:0,2,3,4,5,6,15,17,19 사진의 중복 또는 원스캔이었다. 새 빈 슬롯에 대응하는 자료는 없었다.

같은 날짜의 다른 사진인 `photo/한경직 목사의 총회장 취임식에 축사하는 세계가정생활위원회 하이버 박사-19550426.jpg`, 같은 행사 주제인 a01/a06의 한국기독교 100주년 선교대회 사진들도 검색됐다. 날짜나 행사 주제만 같은 사진은 정확한 원사진으로 단정하지 않았다.

상세 경로, 제목, XML 행, 후보 검증, 파일 SHA-256은 `defect-alternate-search.json`에 기록했다. 전체 익명 이미지나 PSD 레이어를 전수 시각 검사한 것은 아니다. `photo/master.zip` 내부는 Drive 캐시 부족 상황에서 추가로 열지 않았다. 주변 `photo/master/`에는 master01~08의 8개 장면이 이미 존재한다.
