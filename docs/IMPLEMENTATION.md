# 영락교회 PSV 시범 구현

승인된 범위: 로비(scene_f-c-0), A존 입구(scene_a-s-0), 복음의 문이 열리다(scene_a-s-w-1+). 기존 콘텐츠를 활용한 관람 전용 Vercel Preview. CMS, 통계, 챗봇, 유물 회전, 외부 입장 장면 제외.

## 실행 기록
- 원본 폴더는 Git 저장소가 아니므로 독립 psv-poc 프로젝트에서 구현. 원본 파일은 수정하지 않음.
- URL/좌표 테스트를 먼저 작성. 장면 번호는 원래 순서를 알 수 없으므로 임의 매핑하지 않음.
- 로컬 a2_111.xml 조각 대신 list_a02_action.xml의 주석을 제외한 실제 설정과 운영 photo/a02/tour.xml을 대조.
- 원본 3840px 타일은 480px 균등 격자로 재분할. 원본 JPG 디코딩 픽셀과 무손실 WebP의 일치 확인.
- 추출 데이터와 운영 관찰에 따른 보정값을 분리하여 출처 기록.

## 구현 판단 및 수정
- Google Drive 패키지 설치 오류로 로컬 C:에서 빌드하고 작업폴더에 결과를 동기화. 운영에는 영향 없음.
- 원본 메인 XML이 없어 역사 패널 범위와 시작 시점을 시범용으로 보정. 정확한 원형과 다를 수 있어 원본 정의 확보 후 조정 필요.
- 최종 독립 리뷰 4건 모두 수정: 설명문 이미지 유지, 영상 닫기 시 iframe 제거, 이력별 live 시점 기억, 대화상자 키보드 격리.
- 초기 JS 청크 권고(약 281KB gzip)는 남아 있음. 기능 실패는 아니며 후속 성능 최적화 항목.
- 원본 파일과 ZIP은 변경하지 않음. 프로젝트는 독립 Git 저장소이며 GitHub 자동 배포는 연결하지 않음.
